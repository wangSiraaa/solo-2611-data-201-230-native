# Morton分块点数据的矩形范围读取

本目录只包含任务输入和复现实验材料，不含待实现的工具。

离线传感事件带二维整数位置，想把文件布局与矩形查询配合，避免每次扫全表。请用Python 3.11实现build、plan和query。输入JSONL含唯一row_id、x、y和整数value；x/y在0到255，允许相同坐标的多条事件。用8位Morton码交错x/y位，最低位为x的最低位，完整排序键为Morton码及row_id的UTF-8字节，按config指定行数保存不可变块和块目录。
查询是两个左闭右开整数区间，端点在0到256，空区间合法。把矩形与完整256×256整数域的四叉网格相交，形成覆盖查询点的Morton区间；不能只计算两个角点就把它们之间当准确答案。区间统一为左闭右开，并在max_intervals预算下允许合并成更保守的覆盖，但不得漏掉矩形中的任何整数点。plan展示分解/合并依据、候选码区间和选中块。
query依据块目录只打开候选块，再用原x/y做精确残差过滤；保守区间带入的图外点不能出现在结果。输出按row_id字节序排序并保留每个重复坐标事件身份，记录实际打开的块ID及候选行数。块目录中的码界限用于剪枝，不以某块首行坐标代替整个块的空间范围。
布局需包含格式版本、块行数、码最小最大值和摘要，验证输入ID重复、坐标越界和索引绑定；查询源块损坏应明确失败。这里只要求冻结输入、单机、有限几百到几万点，可用普通文件或Parquet保存块；不做GIS重投影、浮点几何、分布式路由、在线更新或B+树。
用原JSONL逐点过滤作独立oracle核对全部现成查询和固定种子的随机小矩形，覆盖跨Morton区间、域上边界、空查询和重复坐标。对8位域可直接枚举所有整数点验证plan无漏覆盖；改变区间预算不得改变最终结果。现成tiny查询应实际少读一些块，报告读取入口记录，不能根据计划伪造。交付源码、布局说明、运行命令和查询产物。
